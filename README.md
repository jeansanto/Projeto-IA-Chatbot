## 🎯 Sobre o Projeto

O Chatbot AI é um assistente virtual desenvolvido com React e integrado à API da Groq.

Ele é capaz de responder perguntas sobre:

* React
* JavaScript
* HTML e CSS
* Programação em geral
* Tecnologias web

## 🚀 Como Executar o Projeto

### 1. Instale as Dependências

```bash
npm install
```

### 2. Instale o Axios

```bash
npm install axios
```

### 3. Obtenha uma Chave da Groq API

Acesse:

https://console.groq.com/keys

1. Crie uma conta gratuita
2. Clique em **Create API Key**
3. Copie sua chave

### 4. Configure a API Key

Abra o arquivo:

```javascript
src/services/groq.js
```

Substitua:

```javascript
const GROQ_API_KEY = 'gsk_sua-chave-aqui';
```

pela sua chave da Groq.

### 5. Execute o Projeto

```bash
npm run dev
```

### 6. Abra no Navegador

```text
http://localhost:5173
```
